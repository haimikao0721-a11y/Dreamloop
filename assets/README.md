# 素材目录

图片放在这里，不放进 `src/`。数值和文案仍在 `src/data/`。字和播放归哪一层见 [docs/05-表现与文字.md](../docs/05-表现与文字.md)。

内容包和引擎不写文件路径。界面以后按 id 来取，用 URL 引用，不把图片 `import` 进 TypeScript。

```
assets/
├─ characters/<roleId>/actions/    角色动作
├─ map/                            地形
├─ items/<itemId>/                 物品
└─ cutscenes/<cutsceneId>/         过场画面
```

## 角色动作

目录名用角色 id，和 `src/data/packs/core/roles.ts` 一致：`dream_archivist`、`ward_nurse`。

`actions/` 只放动作，文件名用动作名：

| 文件 | 动作 |
|---|---|
| `idle.webp` | 待机 |
| `move.webp` | 移动 |
| `attack.webp` | 攻击 |
| `hurt.webp` | 受击 |
| `death.webp` | 死亡 |

立绘以后放同级的 `portrait/`，不和动作帧放一起。

## 地图

地形全地图共用，文件直接放在 `map/`，名字用 `TileKind`：

`wall`、`floor`、`door`、`stairs`

不按角色、不按楼层再拆一套。

## 物品

一种物品一个目录，目录名用 `src/data/packs/core/items.ts` 里的 id，例如 `hollow_tonic/`、`ward_key/`。不按消耗品、遗物、钥匙混放。

## 过场画面

`cutscenes/<cutsceneId>/` 放合成好的一帧（背景、人物、气氛）。不把角色动作、地形、物品复制进来。一幕过场一个目录。

## 占位文件

空目录里的 `.gitkeep` 只为了让目录进仓库。真正的素材放进来之后可以删掉它。

## 程序化生成（当前占位素材）

暂时没有美术，所以现在的素材是**用代码画出来的**：

```bash
node tools/gen-assets.mjs
```

`tools/gen-assets.mjs` 是零依赖的（PNG 编码器自己写，只用 Node 自带的 zlib）。它把**字符画**渲染成 PNG：

```js
const WALL = [
  'llllllllllllllll',
  'ssssssssssssssss',
  'dddsdddsdddsddds',   // 一个字符 = 一个像素
  ...
];
```

这样做的好处：

1. **改图不用装软件** —— 改一个字符就是改一个像素，`git diff` 也看得懂
2. **换皮不换图** —— 同一张字符画配不同调色板，就是另一套地图风格
3. **可复现** —— 改了随时重跑，不依赖谁手里的 psd

美术进场后，把同名的 PNG 换成手画的即可，**文件名和尺寸不用变**。

### 规格

| 项 | 值 |
|---|---|
| 字符画 | 瓦片 16×16，角色 16×24。改图改的是这一层 |
| 输出 PNG | **32 × 32** 瓦片，**32 × 48** 角色。每个字符拆成 2×2 像素，带高光和阴影 |
| 画面 | 画布按 2 倍像素画，显示时缩回原来的页面大小。像素变小，细节才放得下 |
| 格式 | PNG（无损）。`assets/README.md` 原定 `.webp`，因为生成器要零依赖所以先用 PNG，体积敏感时可以批量转 |
| 动作文件 | 一个动作一个文件，帧**横排**在里面，用帧号切片 |

### 动作与帧

| 文件 | 帧数 | 说明 |
|---|---|---|
| `idle.png` | 1 | 待机 |
| `move.png` | 2 | 移动（两帧交替） |
| `attack.png` | 3 | **起手 → 判定 → 收招** |

`attack.png` 的三帧直接对应帧数据的三段：

| 帧 | 阶段 | 含义 |
|---|---|---|
| 第 1 帧 | **起手** | 武器收到身后，还没出来。**对手能看见并躲开** |
| 第 2 帧 | **判定** | 武器扫到身前。**只有这一帧能打到人** |
| 第 3 帧 | **收招** | 武器垂下。**此时挨打最疼** |

### 调色板与地图风格

两套主题**共用同一组字符键**，只是颜色不同：

| 主题 | 位置 | 用在 |
|---|---|---|
| `normal` | `map/` | 常态 —— 凌晨三点十七分的旧医院，冷、灰，只有烛光是暖的 |
| `zero` | `map/zero/` | **理智归零** —— 同一张图，血肉化 |

所以「理智归零切换地图风格」是**换调色板，不是换图**。地形替换（墙变成血肉之类）将来再叠。

角色也一样：`idle.png` 和 `idle_zero.png` 是同一张字符画的两个配色。

### 预览图

`map/_preview.png` 和 `characters/_preview.png` 是放大 5~6 倍的对照图。PNG 在 GitHub 上要一个个点开才看得见，而且 16×16 原尺寸小到看不清 —— 改完素材先看这两张。
